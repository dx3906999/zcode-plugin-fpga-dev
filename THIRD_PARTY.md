# Third-party components

No third-party source code is vendored in this repository.

The optional setup script installs `vivado-mcp==0.3.25` from PyPI into an isolated user-cache virtual environment. That distribution is maintained at <https://github.com/mapleleavessssssss-wq/vivado-mcp> under Apache-2.0; its own package metadata and license govern it.

Other projects named in `docs/research-landscape.md` are references or optional tools only. Naming them does not redistribute, install, or grant rights to their code. Verify their current license and release compatibility before adding them as dependencies.
